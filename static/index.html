การเชื่อมต่อ LINE Official Account & LIFF

เปิดแบบฟอร์มป้อนข้อมูลผ่าน LINE บนมือถือ

ขั้นตอนการตั้งค่า LINE LIFF:

  1. เปิด LINE Developers Console แล้วสร้าง Channel "LINE Login"
  2. ไปที่แท็บ LIFF > กด Add LIFF App
  3. ใส่ Endpoint URL เป็น URL หน้านี้: http://localhost:8000/liff
  4. นำ LIFF ID ที่ได้มาผูกใน Rich Menu หรือส่งให้วิศวกรหน้างานเปิดใช้งานได้ทันที
ทดลองเปิดแบบฟอร์ม LINE LIFF บนหน้าเว็บ

เชื่อมต่อให้ระบบอ่านและเขียนข้อมูลกลับเข้าชีตได้ทันที

2-Way Sync Active

💡 วิธีเอาลิงก์เขียน: ใน Google Sheet ไปที่ ส่วนขยาย > Apps Script > Deploy > Manage deployments > คัดลอก Web app URL มาวางที่ช่องนี้ เมื่อกดแก้ไขบนหน้าเว็บ ข้อมูลจะวิ่งไปเขียนลงเซลล์ใน Google Sheet ทันทีครับ!

ขั้นตอนการ Deploy ใน Google Sheet: ไปที่ ส่วนขยาย > Apps Script > กด Deploy > New deployment > เลือกประเภท Web App (Execute as Me, Access Anyone) > คัดลอก URL มาวางในช่องด้านบน
